# HaulMatch 360 G7 Setup

1. Upload the contents of this complete ZIP to the GitHub repository root.
2. Replace the Apps Script project Code.gs with google-apps-script/Code.gs from this pack.
3. Run upgradeG7Sheets once.
4. Redeploy the existing Web App as a new version, preserving the current /exec URL.
5. Hard refresh the site and test Take Photo, Choose Photos, preview/remove, optional PDF, request submit, Request Uploads, wallet badge, lead unlock debit and credit balance refresh.

The current PayFast flow remains sandbox/test until a VPS and validated PayFast ITN endpoint are live. No real payment is processed by the GitHub/Apps Script simulation.
